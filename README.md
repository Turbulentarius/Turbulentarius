### AI-assisted development

AI is changing the way I learn and work. I currently use tools such as GitHub Copilot and OpenAI Codex as part of my development workflow.

I spend less time on tedious, hands-on code writing and routine debugging, while more of my attention goes into understanding systems, making technical decisions, reviewing implementations, testing assumptions, and figuring out what should actually be built.

AI now handles much of the routine error detection in my workflow, such as spotting syntax errors and other obvious implementation mistakes. That leaves more of my attention for architecture, behavior, edge cases, and whether the implementation actually makes sense.

I also use AI to automate repetitive maintenance work, such as updating dependencies — the kind of task that can easily consume hours when done manually.

More generally, I use tools like Copilot and Codex to handle much of the mechanical implementation work while keeping the understanding and technical decisions on my side. I still review what they produce, test the result, and I am somewhat obsessive about not pushing code I don't understand.

For me, the goal isn't to hand over control. It's to spend less time on mechanical work and more time thinking about the software I'm building.
